App & Data

Your activities, food records, photos and documents are stored in this browser on this device. They are not automatically synced to another phone or computer.

Use Export my records regularly to save a copy of your records. This app does not include a restore/import feature.

Install on Android

Open this app in Chrome over its GitHub Pages HTTPS address. Tap the Install App button when available, or use Chrome menu → Install app.

Storage

Large files and photos use your device browser storage. Avoid clearing Chrome site data if you want to keep your records.
